## 2. 详细启动信息

### 2.1 MinIO

- 进程：`/opt/homebrew/opt/minio/bin/minio server --address :9000 --console-address :9001 /opt/homebrew/var/minio`
- 作用：对象存储服务，供 OSS 上传、下载、预签名访问使用。
- 验证：`http://127.0.0.1:9000/minio/health/live` 返回 `200 OK`。

### 2.2 后端 `ruoyi-admin`

- 启动命令：`java -jar /Users/yabin/code/ruoyi/RuoYi-Vue-Plus/ruoyi-admin/target/ruoyi-admin.jar ...`
- 关键参数：
  - `--spring.profiles.active=dev`
  - `--server.port=8080`
  - 数据源：远程 MySQL
  - 缓存：远程 Redis
  - `--captcha.enable=false`
- 作用：承载 `RuoYi-Vue-Plus` 后端主业务和 `ruoyi-reader` 相关接口。

### 2.3 后台前端 `plus-ui`

- 启动命令：`pnpm dev`
- 实际执行：`vite serve --mode development`
- 作用：后台管理页面开发服务。

### 2.4 C 端 H5 `reader-uniapp`

- 启动命令：`pnpm dev:h5`
- 实际执行：`uni`
- 作用：阅读器 H5 开发服务。

### 2.5 C 端小程序 `reader-uniapp`

- 启动命令：`pnpm dev:mp-weixin`
- 实际执行：`uni -p mp-weixin`
- 作用：微信小程序调试构建进程。
