## 1. 文档目的

这份文档用于统一汇总当前阅读器项目从需求、设计、后端、后台前端、C 端前端到联调上线的全部规划任务，并明确每个阶段的完成情况、当前进展和后续待办，避免在多个计划文档之间来回切换后产生理解偏差。

当前项目已明确采用三仓协同模式：

- 后端基座：`/Users/yabin/code/ruoyi/RuoYi-Vue-Plus`
- 后台前端：`/Users/yabin/code/ruoyi/plus-ui`
- C 端前端：`/Users/yabin/code/ruoyi/reader-uniapp`

## 2. 当前冻结的基础决策

以下决策已经确认，后续不再反复摇摆，除非遇到明确阻塞问题：

| 项 | 冻结结论 |
| --- | --- |
| 后端技术基座 | `RuoYi-Vue-Plus 6.X` |
| 后端工作分支 | `analysis/reader-backend-fit` |
| 后台前端基座 | `plus-ui` |

- 已在 `RuoYi-Vue-Plus` 中建立 `ruoyi-reader` 模块的 P0 业务主链路。
- 已具备 App 端阅读相关接口，包括：
  作品详情
  目录查询
  小说正文读取
  漫画章节读取
  书架管理
  阅读历史
  阅读进度保存与查询
- 已具备后台管理相关接口，包括：
  作品管理
  导入任务管理
  审核管理
  发布/下架操作
- 已实现 Redis 进度缓冲、进度回刷一致性修正、发布内容缓存刷新。
- 已实现导入任务最小可用落地逻辑：
  上传 OSS 文件后创建导入任务
  创建导入文件记录
  创建草稿作品
  小说导入按章节标题自动分章并批量入库
  漫画导入生成最小章节与分页
  自动生成待审核记录
- 已完成导入任务性能与可观测性补强：
  导入任务改为后台异步解析，避免大文件创建任务时阻塞请求
  导入任务支持进度字段：总量、已处理量、进度百分比、进度说明
  小说章节改为批量入库
  漫画分页改为批量入库
- 已实现审核通过后的联动发布逻辑：
  作品发布
  章节同步发布
  发布缓存刷新

- 登录态、游客态、跨端续读的一致性处理
- 首页/我的等页面的正式产品化与文案收敛

### 7.2 后台菜单可见性修正

当前 `plus-ui` 已有阅读器后台路由和页面骨架，但登录后看不到新增模块的根因是菜单/权限接入还没有完全落到后台真实体系里，后续必须补齐：

- 将阅读器后台菜单真正写入并挂接到 `sys_menu`
- 确认 `reader-admin` 路由可被权限体系加载并展示
- 统一“代码路由已存在”和“用户侧菜单可见”这两层状态

### 7.3 首次真实联调冒烟准备

当前最优先的执行任务不是继续无边界扩功能，而是完成第一次真实联调检查，验证以下链路是否真实可用：

1. 后台上传小说文件
2. 后端生成导入任务与草稿作品
3. 后台审核并发布
4. H5 打开作品详情与正文
5. 保存书架、历史、阅读进度
6. 微信小程序继续同一作品阅读
7. 后台下架后验证前台不可见

当前补充说明：

- 由于读者侧正式登录接口尚未落地，第一次联调会优先采用开发态复用现有 Sa-Token 的方案。
- 当前真正的下一阶段阻塞，已经从“页面能力不足”收敛为“真实环境启动 + 首次联调执行”。
- 最近一次联调前置检查已经确认：
  `JDK 21` 正常
  但 MySQL、Redis、后端、后台和 H5 当前均未启动
  因此当前尚未进入真实联调执行阶段

1. 按前端重构方案清理 UniApp 全局视觉壳和页面层级
2. 完成四个一级 Tab：书城、分类、书架、我的
3. 完成搜索、作品详情、章节目录、小说阅读和漫画阅读
4. 补齐 Mock 加载、空数据、失败、游客和阅读设置状态
5. 执行 H5 与微信小程序页面视觉验收
6. 冻结前端接口契约后，再开发后端缺口接口
7. 继续执行真实 P0 联调、身份体系收口和跨端续读验证
8. 再启动 P1 合规授权源同步设计与开发
9. 最后进入运营、数据和上线准备阶段

## 11. 当前结论

当前项目最重要的判断结论有三点：

1. 当前已经不是“要不要做、怎么选框架”的阶段，而是“在既定技术路线下推进 P0 稳定化 + P1 设计”的阶段。
2. 当前最大的未闭环点已经收敛为“身份体系完善、合规授权源同步和上线收口”。
3. 当前最需要做的事情是把 P0 经验固化，然后进入 P1 的可控设计与实施。

## 12. 下一步最优先动作

如果按照当前规划继续执行，下一步优先级建议如下：

1. 在 `reader-uniapp` 上实现竞品学习版前端重构。
2. 用 Mock 数据完成页面和交互验收。
3. 根据冻结后的前端调用点补齐后端接口。
